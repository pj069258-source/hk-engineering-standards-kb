# 香港工程標準知識庫 —— 版權與合規說明

> 建立：2026-10-03 | 用途：香港工程業界（水、電、裝修、防水等）AI 應用培訓之權威知識庫
> 本文件是這個知識庫的**法律邊界說明**，發佈/培訓前請先讀完。

---

## 一、知識庫的「權威性」如何保證

每條條目都必須帶以下欄位，缺一不可：

| 欄位 | 作用 |
|---|---|
| `authority` | 發佈機構（如水務署、機電工程署、屋宇署、勞工處） |
| `authority_level` | 效力等級：**法定條例 / 附屬法例 / 官方指引 / 官方實務守則 / 業界標準** |
| `source_chapter` | 具體條文出處（如《水務設施條例》(Cap. 102) 第 X 條） |
| `url` | 官方連結（可回溯核查） |
| `verified` | 查證日期 |
| `confidence` | 查證信心（high/low）——`low` 者**不得**作為培訓教材的依據 |

**鐵律：法定要求與業界慣例必須分開標示。** 政府沒有強制標準的範疇（例如部分防水做法），一律標為「業界標準」，嚴禁寫成「法例規定」。

## 二、版權與合規（已查證）

### 1. 香港法例文本受政府版權保護

《版權條例》(第 528 章) **第 16 條**明確提及「**政府版權**」及「立法會版權」（參看第 182 及 184 條）。
→ **法例文本並非無版權的公共領域材料**，不可整章複製轉載。

### 2. e-Legislation 的法定地位規則（極重要）

依「電子版香港法例」[重要告示](https://www.elegislation.gov.hk/importantnotices)：

- 只有內頁印有「**經核證文本**」官方核證標記的 **PDF**，才屬該法例的**經核證文本**，具法律地位
  （依《法例發布條例》(第 614 章) 第 5 條，推定為該文本指明日期的正確表述）
- **HTML 及 RTF 版本「僅供參考」**
- **簡體中文版本由軟件轉換，只供參考**；如有差異，**以繁體中文版本為準**

→ 因此：本知識庫的條目**不得**被當作法律文本使用；引用時必須指向 e-Legislation 的經核證文本 PDF 連結。

### 3. 政府資料的再利用授權

依 [data.gov.hk 使用條款及條件](https://data.gov.hk/tc/terms-and-conditions)（2025-05-26 版）：

- 可免費瀏覽、下載、分發、複製、列印，作**商業及非商業用途**
- **條件**：必須遵守使用條款；**必須在資料及其所有複製本上清楚註明來源，並確認政府及有關機構為知識產權擁有人**；須就侵權申索作出彌償
- 資料以「**現況**」提供，政府**不作任何準確性、完整性、適時性保證**，亦不承擔使用引致的法律責任

### 4. 本知識庫採取的合規做法

| 做法 | 原因 |
|---|---|
| **改寫而非複製**：以自己語言歸納要求 | 避免侵犯政府版權 |
| `quote` 欄位**最多 30 字**原文片段 | 僅為確保關鍵術語準確，屬有限引用 |
| 每條附**來源機構 + 條文編號 + 官方連結** | 履行 data.gov.hk 條款的註明來源義務 |
| 明確標示政府為知識產權擁有人 | 同上 |
| **不收錄**法例全文、不作全文鏡像 | 避免實質複製 |
| 標示查證日期 `verified` | 法例會修訂，便於日後更新 |

## 三、免責聲明（培訓材料必須一併附上）

> 本知識庫由第三方（非政府）整理，**並非香港特別行政區政府或其任何部門的官方出版物**，亦**不構成法律意見**。
> 內容以政府公開資料為基礎改寫而成，知識產權屬香港特別行政區政府及有關機構所有。
> 法例可能隨時修訂；**只有「電子版香港法例」上印有「經核證文本」標記的 PDF 才具法律地位**，HTML/RTF 及簡體版本均僅供參考。
> 使用者在作出任何工程、商業或法律決定前，應查閱最新的官方文本，並徵詢註冊專業人士（如註冊結構工程師、註冊電業承辦商、持牌水喉匠、註冊安全主任）的意見。
> 本知識庫的整理者及使用者，概不就因使用或依據本知識庫內容而引致的一切損失或損害承擔責任。

## 四、AI 培訓場景的額外注意

1. **不可宣稱官方認可**：不得以「政府認可」「官方指定」等字眼宣傳本知識庫或相關 AI 應用。
2. **必須保留出處顯示**：AI 回答時要顯示 `authority` + `source_chapter` + `url`，讓學員能自行核查。這是本知識庫相對一般 AI 問答的核心價值。
3. **`confidence: low` 的條目**：只可作課堂討論素材，不可作為標準答案。
4. **教管理層「查證」而非「相信」**：建議在培訓中示範用 e-Legislation 核對條文，讓學員建立「AI 給出處 → 自己查原文」的習慣。
5. **商業用途**：data.gov.hk 條款允許商業用途，但若你日後要**轉售**此知識庫或對外提供服務，仍須自行確認各來源機構的個別條款（部分機構網站有獨立版權告示）。
